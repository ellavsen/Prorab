# Журнал разметки eval-набора

Набор собран из двух: черновика AI-контракта (`source: fable_draft`, 40) и
сгенерированного под спринт (`source: generated`, 49). Один пример отброшен как
дубль — E16 и v05 оказались одной фразой про полтора куба бетона.

Слияние вскрыло **противоречия в разметке**: два набора по-разному размечали
структурно одинаковые случаи. Это находка, а не стыд. Модель на прогоне честно
поставила один и тот же ответ там, где эталоны расходились, и получила промах в
обоих — так расхождение и обнаружилось. Замер оказался точнее собственной
разметки.

Ниже — что и почему переразмечено.

---

## E14 — `price.scope`: `unknown` → `per_unit`

```
вход:  «штукатурка сто квадратов, семьсот»
было:  price.scope = "unknown"
стало: price.scope = "per_unit"
```

**Почему.** Черновик размечал цену без явного маркера как `unknown`.
Сгенерированный набор такую же форму («Побелка, 150 м2, 3000») размечал
`per_unit`. Структурно это одно и то же: наименование, количество, число.

Правило переформулировано **от умолчания, а не от формата**:

- `per_unit` — умолчание;
- `total` — только при явных словах: «за всё», «всего», «итого», «под ключ»,
  «за работу целиком»;
- `unknown` — только когда цена названа в речи без маркера **и** без структуры
  строки.

**Что это значит для расчёта.** Ничего: `unknown` считается как `per_unit`,
третьей ветки расчёта нет. Но такая строка помечается в предпросмотре
подсказкой «если это за всё — нажми ÷», и кнопка деления у неё есть. Решает
человек, а не умолчание.

## E25 — `category`: `unknown` → `work`

```
вход:  «гидроизоляция десять квадратов по пятьсот»
было:  category = "unknown"
стало: category = "work"
```

**Почему.** Гидроизоляция — и вещество, и работа, и по части речи её не
развести. Развести можно по **единице**:

- площадь, объём, длина (м², м³, м.п.) → `work`;
- штучная или весовая (шт, кг, т, л, компл, мешок, рулон, упак) → `material`;
- единицы нет вообще → `unknown`.

Здесь единица — м², значит работа. **Модель была права, а эталон нет.**
«Гидроизоляция два мешка» по тому же правилу дала бы `material`.

---

### Правило категории сужено после проверки на наборе

Первая формулировка была общей: «единица площади, объёма или длины → work,
штучная или весовая → material». Прогон по набору показал, что она
**противоречит 29 эталонам из 85**: плитка, ламинат, песок, бетон, плинтус,
кабель и утеплитель — материалы, которые меряют в м², м³ и м.п.; вывоз мусора
считают в тоннах, работу электрика в часах, монтаж розеток в штуках.
Применить её значило бы увести `category` с 2 ошибок до ~29.

Правило оставлено там, где оно верно — **как тай-брейк для гибридных слов**,
означающих сразу и вещество, и работу: гидроизоляция, затирка, шпаклёвка,
штукатурка, стяжка. Для «плитки» и «покраски» по-прежнему решает то, вещь это
или действие.

## E39 — `category`: `material` → `unknown`, и парный к нему E41

```
вход:  «затирка две по восемьсот»
было:  category = "material"
стало: category = "unknown"
```

**Почему.** Затирка — гибридное слово, значит решает единица. Единицы здесь
нет вообще, значит по правилу `unknown`. Прежний `material` следовал из
интуиции, а не из правила, и делал пример недостижимым.

**Вход не переписан намеренно.** Ценность примера ровно в отсутствии единицы;
правка входа под желаемый ответ — подгонка данных, а не разметка.

Вместо этого добавлен **E41** — то же слово со штучной единицей:

```
вход:   «затирка два мешка по восемьсот»
эталон: category = "material", unit_spoken = "мешок"
```

Теперь проверяются обе ветки тай-брейка, а не одна.

не ответы:

| recall v2 | 0.792 | **0.812** |
| precision v2 | 0.792 | **0.812** |

Сравнивать v3 нужно именно с **0.812**: одна и та же разметка по обе стороны.
