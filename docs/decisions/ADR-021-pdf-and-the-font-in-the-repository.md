# ADR-021. PDF на reportlab, шрифт — в репозитории

**Статус:** принято, Sprint 7.

**Контекст.** Заказчику нужен документ, который открывается везде и выглядит
одинаково. XLSX для этого не годится: он редактируем по замыслу (в нём живут
формулы), а половина заказчиков откроет его в браузере или не откроет вовсе.

Два требования сузили выбор до одного варианта: **чистый Python без системных
зависимостей** (CI и хост бота не должны обзаводиться нативными библиотеками)
и **кириллица, не зависящая от системы** (в контейнере CI кириллических
шрифтов нет).

**Решение по библиотеке.**

| | лицензия | вердикт |
|---|---|---|
| **reportlab** | BSD-3 | взято: чистый Python, встраивание TTF, кириллица |
| fpdf2 | LGPL-3.0 | LGPL в MIT-проекте требует оговорок; отказ ради простоты лицензионной картины |
| WeasyPrint | BSD, но нужны pango/cairo/harfbuzz | нарушает требование «без системных зависимостей» |
| borb | AGPL | исключено |

**Решение по шрифту.** PT Sans Regular, **SIL OFL 1.1** — коммерческое
использование и встраивание в документы разрешены явно. Лежит в
`packages/smeta_export/fonts/` вместе с полным текстом лицензии.

1. **Одно начертание.** Заголовки различаются кеглем, а не жирностью: второе
   начертание удвоило бы вес ради эффекта, которого можно добиться иначе.
2. **Subset скриптом, а не бинарником из ниоткуда.**
   `scripts/subset_font.py` показывает, что взято, откуда, что выброшено и
   почему. Бинарник без происхождения невозможно проверить на ревью.
3. **Переименование обязательно.** В шапке OFL: `with Reserved Font Names
   "PT Sans" and "ParaType"`. Урезание — это модификация, а модифицированная
   версия не может носить зарезервированное имя. Семейство названо
   `ProrabSans`; идентификатор шрифта переписан целиком, потому что заменой
   подстроки в нём осталось бы «ParaTypeLtd». Копирайт ParaType внутри файла
   **сохранён**: он не имя, а указание авторства, и OFL требует его оставить.

**Размер — измерен, а не оценён.**

| | |
|---|---|
| исходный PT Sans Regular | 432,6 КБ |
| subset до нужных символов, с хинтингом | 90,4 КБ |
| **+ без хинтинга и лигатур** | **21,0 КБ** |

Хинтинг оказался 69 КБ из 90 — три четверти файла. Это инструкции
растеризации для мелких кеглей на экранах низкой плотности: в печати они не
участвуют, а просмотрщики PDF растеризуют своими средствами. Лигатуры в
русской смете не встречаются и стоили ещё 5 КБ. Репозиторий вырос на ~6%
вместо ожидавшихся 25%.

**PDF ничего не вычисляет.** `EstimateTotals` приходит снаружи, и у
отправленной сметы это результат сверки со слепком (money.md И3). Промежуточные
итоги по разделам считает `sum_lines` из ядра — иначе в проекте появилось бы
второе правило сложения денег, и оно разошлось бы с первым ровно так же, как
расходились четыре вычислителя до Sprint 1.

**Последствия.**

- Новая рантайм-зависимость одна: `reportlab`. `pypdf` и `fonttools` —
  только для тестов и пересборки шрифта.
- Правило «умножает только калькулятор» уточнено, а не ослаблено: умножение на
  единицы вёрстки (`18 * mm`) разрешено по имени операнда, список закрыт.
  Умножение денег в генераторе PDF по-прежнему невозможно.
- Документ не содержит ничего о владельце: поле автора пустое намеренно,
  проверяется тестом.
