# ADR-007. Раскладка пакетов и машинно проверяемые правила слоёв

**Статус:** принято, Sprint 2.

**Контекст.** Весь бот был одним файлом на 941 строку: конфиг, модели, миграции,
состояние, парсинг, хендлеры, генерация Excel и bootstrap подряд. Правило «ядро
не импортирует транспорт» существовало только в документе.

**Решение.**

```
packages/smeta_core     чистый домен: stdlib + Decimal
packages/smeta_storage  SQLAlchemy, миграции, репозиторий
packages/smeta_export   openpyxl
apps/bot                python-telegram-bot, тонкие хендлеры
```

`packages/` — библиотеки, `apps/` — приложения; оба корня перечислены в
`[tool.setuptools.packages.find] where`, поэтому обычный `pip install -e .`
ставит и то и другое.

Правила слоёв проверяет `tests/test_architecture.py` разбором AST, а не ревью:

- `smeta_core` не импортирует telegram, sqlalchemy, openpyxl, HTTP-клиенты;
- `smeta_storage` не знает про telegram и openpyxl;
- `smeta_export` не знает про telegram и sqlalchemy;
- `apps/bot` не импортирует sqlalchemy и openpyxl напрямую;
- умножение допускается только в `calculate.py` и `money.py` — нигде больше
  деньги не умножаются;
- ни один файл не длиннее 300 строк (максимум сейчас 174);
- слова `user_category`, `current_estimate_cache`, `func.sum`, `TAX_RATE` не
  встречаются нигде.

Конфигурация `ruff` зафиксирована явным списком правил в `pyproject.toml`:
иначе фраза «линтер не находит мёртвого кода» зависела бы от версии линтера.
`RUF001-003` отключены — они помечают каждую кириллическую букву, похожую на
латинскую, а интерфейс проекта русский по требованию.

**Альтернативы.** Один пакет с подмодулями — правило слоёв осталось бы
пожеланием. Отдельные дистрибутивы с версиями — несоразмерно одному репозиторию.

**Следствия.** Точка входа сменилась: вместо
`python python3/webservice/telegram/main_agent.py` теперь `python -m bot.app`.
Каталог `python3/webservice/telegram/` удалён, `requirements.txt` переехал в
корень. Токен больше не требуется на импорте — проверка переехала в
`require_token()`, вызываемый из `build_app()`, поэтому модули бота можно
импортировать и тестировать без секретов.
